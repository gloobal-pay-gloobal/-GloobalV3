**Work done**

- **`qrEncoder.js` — expose the function-module map.** `qrBuildMatrix(text)` returned only `matrix`; it now returns `{ matrix, isFunctionModule }`. `isFn` was already built internally — it just never left the function. The renderer needs the distinction: finder / timing / alignment / format-info / dark-module cells must stay plain standard squares for a decoder to lock on, while every dark **data** cell can be drawn as any shape with equivalent ink coverage.
- **`gloobalQRCode.jsx` (+157) — mosaic renderer.** Consumes the new map; styles data modules only.
- **Scan → pay honesty chain.** `App.jsx` now carries `registered: Boolean(scanPendingPayment.registered)` through to Send Money, so an unregistered ID no longer arrives indistinguishable from a real one. A new `scanSettledRemotely` flag is hoisted out of the `if (amount > 0)` block so the closing toast can tell a real send from a skipped one:
  - real send → `Paid $X — verified and locked`
  - skipped → `Not sent — $X recorded locally only, no registered Gloobal account to credit`
- **History status.** Transaction `status` is now `settledRemotely ? "completed" : "simulated"` — previously always `"completed"`, which meant History and the reopened receipt (the only records a user can go back and check) showed fake success next to money that was never posted.
- **`ReceiptModal.jsx`.** New `"simulated"` status handling: header suffix `· Not actually sent`, status row `Not sent — simulated`, plus a `role="alert"` amber banner explaining the recipient wasn't a registered Gloobal account.
- **`TransactionRow.jsx`.** Amber `Not sent` pill in the row meta, `flexWrap` on the meta line, and an extended `aria-label`: `View receipt for …, … — not actually sent, simulated only`.
- **`dialPads.jsx` — desktop tap bug.** `setPointerCapture` was called on every `pointerdown`. Once a parent captures the pointer, a mouse down+up over a child **never** dispatches `click` in Chromium, while a touch tap still does — which is exactly why the dial pad answered taps in mobile preview but not on a laptop trackpad. Fix: skip capture when `e.target.closest("button")` matches; the open ring background still supports the drag-to-rotate gesture.
- **`SendMoney.jsx` (+68).** Unregistered-recipient warning surfaced before the person pays.

### 7.15 Operational lessons recorded that session

- **Netlify MCP deploy status is untrustworthy in both directions.** It reported `500 Internal Server Error` on a deploy that succeeded, and 502'd repeatedly on ones that later worked.
